# Задание 1
## Задача 10
### Текст задачи
Измените сущности City. Гарантируйте, что между двумя городами может быть только одна прямая дорога (другой путь может быть проложен только транзитом через другие города). Города можно создавать с указанием заранее заданных путей, в любой момент времени можно добавить новую дорогу в любой город и удалить имеющуюся дорогу.

### Алгоритм решения
1. Создан класс `City` с полями: название, массив связанных городов и массив стоимостей
2. Реализована проверка уникальности связей при добавлении дороги
3. Добавлены методы:
   - `addPath()` - добавление новой дороги с проверкой на дублирование
   - `removePath()` - удаление существующей дороги
   - `findCityIndex()` - вспомогательный метод для поиска города в массиве связей
4. Обеспечена защита от добавления связи города с самим собой
5. Конструкторы поддерживают создание как пустого города, так и города с предустановленными связями

# Задание 2
## Задача 5
### Текст задачи
Основная идея задачи в разработке такой сущности, которая будет представлять собой маршрут между двумя городами. Данный маршрут в любой момент времени можно получить как массив для дальнейшего использования. Сущность Маршрут имеет следующие характеристики:
- Имеет Город начала и Город конца пути
- Инициализация Маршрута может быть выполнена только если указана точка начала и конца пути. Если указано null значение - то ошибка
- Точку начала и конца можно изменить в любой момент времени, но они всегда должны существовать
- Может вернуть массив Городов, представляющий собой маршрут из начала в конец. Массив содержит все Города (в порядке очереди) через которые надо пройти чтобы попасть из Города начала в Город конца, причем и начало и конец также содержатся в этом массиве
- Маршрут может быть приведен к строке, которая будет возвращать название всех городов маршрута в порядке очередности
- Создание объекта и изменение точек начала и конца выполняется за константное время O(1)

### Алгоритм решения
1. Создан класс `Route` с полями: начальный и конечный город
2. Реализован алгоритм поиска пути в ширину (BFS) в методе `getRoute()`
3. Использованы структуры данных:
   - `LinkedList` для очереди городов
   - `HashMap` для хранения информации о пути
4. Метод `buildPath()` восстанавливает путь от конечного города к начальному
5. Переопределен метод `toString()` для красивого вывода маршрута
6. Добавлены проверки на null при инициализации и изменении городов

# Задание 3
## Задача 3
### Текст задачи
Создайте такой подвид сущности Город, полученной в задаче 1.10, которая будет гарантировать, что при добавлении дороги из одного города в другой, одновременно будет добавляться и обратная дорога.

### Алгоритм решения
1. Создан класс `TwoWayCity` наследующий от `City`
2. Реализован метод `addTwoWayPath()` который:
   - Добавляет дорогу в текущий город
   - Проверяет наличие обратной дороги в другом городе
   - При отсутствии обратной дороги - добавляет её
3. Переопределен метод `addPath()` для автоматического создания двусторонних связей
4. Конструкторы поддерживают создание как пустого города, так и города с предустановленными двусторонними связями

# Задание 4
## Задача 3
### Текст задачи
Птицы. Создайте сущность Птица, которая будет являться корнем иерархии для всех, кто является подвидом птицы. В разработанную сущность необходимо вынести все, что будет общим для птиц. Для того чтобы определить необходимые члены класса, проанализируйте три примера птиц:
- Воробей. Умеет петь. При пении на экран выводится строка "чырык"
- Кукушка. Умеет петь. При пении на экран выводится текст "ку-ку", причем текст выводится случайное количество раз в диапазоне от 1 до 10
- Попугай. Имеет текст и умеет петь этот текст. При инициализации обязательно необходимо указать текст, который будет исполняться. При пении текст выводится не весь, а первые N символов (не менее одного и не более всех символов текста), где N определяется случайно

### Алгоритм решения
1. Создан абстрактный класс `Bird` с полем `name` и методом `sing()`
2. Реализованы классы-наследники:
   - `Sparrow` - переопределяет `sing()` для вывода "чырык"
   - `Cuckoo` - использует Random для генерации случайного количества "ку-ку" (1-10 раз)
   - `Parrot` - принимает текст в конструкторе, выводит случайное количество символов (1-длина текста)
3. Добавлены проверки на валидность входных данных
4. Реализован полиморфизм - общий интерфейс для всех птиц

# Задание 5
## Задача 9
### Текст задачи
Городим. Реализуйте граф показанный на рисунке, используя в одной и той же программе и сущности из задачи 1.10 (односторонняя дорога) и сущности из задачи 3.3 (двусторонняя дорога) применяя их там, где это необходимо. На рисунке односторонняя стрелка обозначает что возможно перемещение только в одном направлении (например только из пункта E в пункт C), а двусторонняя стрелка говорит о том, что возможно перемещение в обоих направлениях (например из A в B и наоборот).

### Алгоритм решения
1. Создана смешанная сеть городов:
   - Двусторонние города: A, B, D, E (используют `TwoWayCity`)
   - Односторонний город: C (использует обычный `City`)
2. Установлены связи согласно графу:
   - Двусторонние: A↔B, A↔C, B↔D, D↔E
   - Односторонние: B→C, E→C
3. Продемонстрированы различные маршруты, показывающие разницу между одно- и двусторонними связями
4. Показана недостижимость некоторых маршрутов из-за односторонних ограничений
